    Проверка сохранности данных

    1. Напишите пару сообщений в гостевую книгу и сделайте снимок: запомним число сообщений и их SHA-256.
    2. Убейте поды: автора снимка, базу postgres-0 или всё сразу.
    3. Проверка идёт сама каждые 2 секунды, и выполняет её уже другой под.
    Снимка пока нет.

    Наблюдаемость

    /metrics — метрики этого пода в формате Prometheus
    Prometheus (make prometheus): RPS по подам · p95 латентности · действия из UI · кто жив (up)
    kubectl -n kube-demo logs <pod> -c access-log -f — access-лог из sidecar-контейнера
    kubectl -n kube-demo top pods --containers — CPU/память (нужен metrics-server)

    Что смотреть в терминале

    kubectl -n kube-demo get pods -o wide -w — поды, ноды, RESTARTS, READY
    kubectl -n kube-demo get endpointslices -w — кто сейчас в балансировке
    kubectl -n kube-demo logs -l app=kube-demo -f --prefix — логи всех подов
    kubectl -n kube-demo set env deploy/kube-demo APP_COLOR=seagreen — rolling update
